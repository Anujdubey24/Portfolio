# Anuj Dubey — Developer Portfolio

Created by Anuj Dubey.

## Summary

A responsive, single-page portfolio for presenting my web development work, skills, certificates, resume, and contact details to internship recruiters. It includes an AirData project gallery, certificate carousel, image previews, and copy buttons for my email and phone number.

## Project files

- `index.html` contains the page content and links.
- `style.css` controls the theme, layout, responsive design, and animations.
- `script.js` handles navigation, galleries, certificate previews, and contact copy buttons.
- `assets/` contains the profile photo, resume, favicon, project screenshots, and certificate images.

## Preview locally

Open `index.html` in a browser, or open the project folder with a local web server such as the Live Server extension in Visual Studio Code.

## Make updates

- Edit text and links in `index.html`.
- Change colors, spacing, and layout in `style.css`.
- Change gallery and button behavior in `script.js`.
- Replace images or the resume in `assets/`, keeping the filenames the same unless you also update their paths in `index.html`.

## Publish with GitHub Pages

Push this project to a GitHub repository. In the repository, open **Settings → Pages**, select the `main` branch and the root folder, then save. GitHub Pages will provide a public link when publishing finishes.
